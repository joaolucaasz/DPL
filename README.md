# 🐾 My Pokedex

Uma experiência interativa para explorar o universo Pokémon, consultar informações e descobrir diferentes espécies em um único aplicativo.

## 💡 Conceito do Projeto

O **My Pokedex** é um aplicativo mobile desenvolvido com a proposta de reunir informações sobre o universo Pokémon em uma plataforma intuitiva, acessível e interativa.

Inspirado nas Pokédex presentes no universo Pokémon, o projeto busca reproduzir digitalmente a experiência de consultar, descobrir e acompanhar diferentes espécies.

A aplicação permite que os usuários explorem Pokémon, visualizem suas características, acompanhem seus favoritos e tenham acesso a recursos complementares, proporcionando uma experiência organizada e dinâmica.

O projeto também tem como objetivo aplicar conhecimentos de desenvolvimento mobile, integração com APIs, gerenciamento de dados e construção de interfaces.

## ✨ Funcionalidades

- **Listagem de Pokémon:** visualização dos Pokémon disponíveis.
- **Detalhes:** consulta de informações individuais dos Pokémon.
- **Favoritos:** gerenciamento dos Pokémon favoritos.
- **Histórico:** armazenamento dos últimos Pokémon visualizados.
- **Câmera:** funcionalidade de acesso à câmera.
- **Autenticação:** tela de login.
- **Notificações:** suporte a notificações locais.
- **Sobre:** página com informações do aplicativo.

## 🛠️ Tecnologias utilizadas

- React Native
- TypeScript
- Expo
- JavaScript
- PokeAPI
- AsyncStorage
